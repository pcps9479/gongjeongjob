# 공정잡 (GongjeongJob) — 인테리어 공정별 구인구직 앱 프로토타입

타일·목공·철거·도배·마루·필름·전기·설비까지, **인테리어 6개 공정의 구인·구직 · 공수(출역) 관리 · 수입 정산**을 한 앱에서 처리하는 모바일 프로토타입입니다.
Expo SDK 58 (React Native 0.88 + React Native Web) 기반이라 **Expo Go(아이폰)** 와 **웹 브라우저**에서 바로 확인할 수 있고, **GitHub Pages 정적 웹**으로 그대로 배포할 수 있습니다.
회원가입·로그인(역할 선택·휴대폰 인증), 알림함, 노쇼·임금체불 신고(안전센터), 계정/약관 관리에 더해 **기술자가 직접 올리는 구직 자기소개(시공 사진 포함)**, **발주처의 섭외·연락 요청**, **발주처 조건 선택형 ⚡ 긴급 펑크 자동 매칭**, **공정별 스폰서 배너(광고·제휴 문의)** 까지 실제 서비스 흐름을 갖췄습니다.

> 기존 `타일잡`(타일 전용) 프로토타입의 타일 기능·상태 구조를 그대로 유지하면서, 공정 선택 구조와 공정별 데이터를 확장했습니다.

## 1. 바로 실행하기

```bash
cd tile-job-app
npm install          # 최초 1회

npx expo start       # QR 코드가 뜨면 아이폰 Expo Go 앱으로 스캔
npx expo start --web # 브라우저에서 바로 보기
```

> **Node 버전**: Expo SDK 58은 Node **22.13 이상**을 요구합니다. (`node -v`로 확인)

Expo Go 실행 순서

1. 아이폰 App Store에서 **Expo Go** 설치
2. 위 명령 실행 → 터미널의 QR 코드를 아이폰 카메라로 스캔 (또는 Expo Go 앱에서 코드 입력)
3. 같은 Wi-Fi에 연결되어 있어야 하며, 안 되면 `npx expo start --tunnel` 사용

### 검증 명령

```bash
npm run typecheck    # npx tsc --noEmit — 타입 오류 0건
```

## 2. 공정 전환 구조

### 공정 탭 (일자리 피드 상단)

`전체` / `타일` / `목공` / `철거` / `도배·마루` / `필름` / `전기·설비` — 7개 탭이 2줄로 모두 보이고, 탭마다 **현재 공고 수**가 표시됩니다.
공정을 고르면

- 피드 제목·요약(공정 태그라인, 임박 공고 수)이 바뀌고
- **시공 유형 필터 칩**이 그 공정 전용으로 교체되며
- **공고 카드의 단가 기준·자재 규격·현장 조건**이 그 공정 기준으로 표시됩니다.

## 3. 구현된 화면

하단 4개 탭 구조이며, 모든 상태(등록 공고·지원·공수·프로필)는 앱 안에서 실제로 연동되고 AsyncStorage에 저장됩니다.

### ① 일자리 (피드)
- **공정 탭 7종** + 공고 수 → 공정 전환 시 시공 유형 칩·카드 자동 전환
- **필터 3종**: 지역(서울/경기/인천/부산/대전…), 직급(기공/준기공/조공), 시공 유형(공정별)
- **정렬**: 최신순 ↔ 급여 높은순(도급은 예상 총액으로 환산)
- **공고 카드**: 공정 배지, 시공 부위, 현장 지역·날짜·집합 시간, 단가 방식(일당/도급)과 단가 기준(㎡·평·톤·롤·면·세트·개소·건)·예상 총액, 필요 인원, 자재·규격, 발주처 인증 배지·평점·거래 건수, D-day, 지원 완료 표시
- **상세 시트**: 공정·자재 규격·시공 부위, **공정별 현장 조건**(예: 목공 타카·콤프, 철거 폐기물 처리, 필름 열풍기, 전기 자격증), 현장 메모, 발주처 이력(노쇼 0회·임금체불 0건), **안심 매칭 안내**(채용 확정 전 연락처 비노출), **원터치 지원하기**(지원 완료 ↔ 다시 눌러 취소)
- 하단 **지원 현황** 카드에서 내가 지원한 공고 확인

#### 기술자 자기소개 피드 (피드 상단 `현장 공고 ↔ 기술자 소개` 전환)
- 같은 피드에서 **현장 공고 ↔ 기술자 소개**를 한 번에 전환하고, **공정 탭·지역 필터가 그대로 연동**(등급 필터는 자기소개 등급, 시공 필터는 가능한 시공에 적용)
- 카드 정보: 이름/닉네임(**이름 마스킹** 선택), **공정·등급·경력**, 출역 가능일(오늘·이번 주·11/25부터)과 지역, **한 줄 자기소개**, 보유 공구, **희망 일당(또는 협의)**, 평점·완료 현장 수
- **`시공사진 보유` 배지**: 시공 사진(작업물)이 1건 이상인 기술자 카드에 표시되고, 카드를 누르면 **시공 부위·설명과 사진 미리보기**를 시트에서 확인
- 카드·상세 시트의 **`섭외·연락 요청`** 버튼 → 요청 전송(수락 후 연락처 공개, 이름 마스킹 기술자는 수락 후 실명 공개). 요청 상태는 저장되어 `섭외 요청함`으로 표시
- 내 자기소개 카드 아래 **`긴급 출역 알림`** 스위치: **오늘 / 내일**을 켜고 끄면 긴급 펑크 자동 매칭 대기 풀에 바로 반영(ON인 기술자는 발주처 알림을 먼저 받음)

#### ⚡ 긴급 펑크 자동 매칭 (발주처 조건 선택)
- 피드 상단과 **공고등록 탭**의 `⚡ 긴급 펑크 자동 매칭` 카드로 진입하는 시트
- 발주처가 직접 고르는 조건: **공정**(6종, 바꾸면 필수 스킬 자동 전환) · **지역** · **필요 직급**(무관/기공/준기공/조공) · **최소 경력**(무관/3년+/5년+/10년+) · **필수 시공 스킬**(복수) · **필수 공구 지참** 토글 · **일당 상한**(18~60만 원, 1만 원 단위) · **시공사진 보유 필수** 토글
- 조건을 바꿀 때마다 **지금 조건에 맞는 N명**이 실시간으로 다시 계산되고(대기 풀 대비), 조건에 맞는 기술자 미리보기(이름 마스킹)가 표시
- **`조건 맞는 N명에게 매칭 알림 보내기`** → 동시 알림 → **선착순 1명 수락 시뮬레이션**: 수락 카드(등급·경력·평점·시공사진·공구) + **연락처 공개(데모 번호)** + **`성사 시에만 매칭 수수료 부과 · 미성사 시 0원`** 안내 → `매칭 확정`까지 한 흐름
- 수락 결과는 **알림함에 기록**되고, 기술자 수락 시 이름 마스킹이 해제됩니다
- 대기 풀은 `오늘·내일 긴급 출역 ON` 기술자와 출역 가능일이 오늘·내일인 기술자로 구성(현재 8명 시드)

#### 스폰서 배너 (광고 예시)
- 일자리 피드 **2번째 공고 아래**에 흐름을 방해하지 않는 **1줄 스폰서 배너(AD)** 삽입
- 선택된 공정에 따라 자동 전환: **철거 → `폐기물·스카이 당일 호출`**, **타일·목공 → `1톤 용달·온라인 건재몰 긴급배송`**, **전체·기타 → `현장 전동공구·부자재 특가`**
- 배너 탭 → **데모 광고 안내 모달**(연결 방식·광고 단가 예시·"실제 제휴 시 전화 연결/주문 링크로 이동" 안내)

### ② 공고등록
- **1단계: 모집 공정 선택**(6개 공정 카드) → 선택 즉시
  - 급여 **단가 방식 세그먼트**가 그 공정의 방식(일당 / ㎡·평·톤·롤·면·세트·개소·건당 도급)으로 전환
  - 도급 선택 시 **면적 라벨·단위**(시공 면적 ㎡ / 시공 평수 / 폐기물 톤수 / 도배 롤 수 / 시공 면 수 / 세트 수 / 개소 수 / 건수)와 **총액 자동 계산**
  - **시공 부위 칩**과 **자재·규격 칩**(타일 규격 / 목재·자재 / 철거 범위 / 도배지·마루재 / 필름 종류 / 배선·기기 규격) 교체
  - **현장 조건 체크박스**가 공정 라벨(목재·부자재 구비, 장비·자재 구비 등) + 공정별 추가 항목으로 교체
- 현장명·발주처·지역·세부 지역·작업일(향후 21일)·집합 시간, 직급별 인원 스테퍼
- 필수 항목 검증 후 등록 → **해당 공정 피드로 이동해 최상단 노출**(`내가 등록` 배지)
- 상단 **`현장 공고 ↔ 기술자 자기소개` 전환**: 기술자 계정은 기본이 **내 구직 자기소개**(미리보기·수정·피드에서 보기), 발주처 계정은 기술자 자기소개 안내(등록 수·시공사진 보유 수·오늘 출역 가능 수)와 **기술자 소개 보기** 링크를 제공합니다.
- 현장 공고 폼 위에 **`오늘 사람이 빠졌나요? 긴급 펑크 자동 매칭`** 진입 카드 — 공고를 등록하지 않고 조건만 골라 바로 알림을 보낼 수 있습니다.

#### 구직 자기소개 작성/수정 시트
- 주력 공정(복수)·등급·경력, **출역 가능일(향후 14일)·가능 기간·출역 지역(복수)**
- **한 줄 자기소개**(90자, 예시 문구), 가능한 시공·보유 공구(공정별 선택지)
- **희망 일당**(숫자 입력 또는 `협의`), **이름 마스킹** 옵션
- **시공 사진·작업물(선택, 최대 3건)**: 샘플 현장 사진 선택 + **시공 부위 + 한 줄 설명** → 1건만 올려도 카드에 `시공사진 보유` 배지
- **긴급 출역 알림**: 오늘·내일 긴급 출역 ON/OFF를 자기소개에 함께 저장

### ③ 공수달력
- 월별 캘린더(주말 색 구분, 오늘 표시), 날짜 칸에 **공수 숫자 + 상태 색**(예정·확정·완료)
- 상단 요약: **이번 달 총 공수**, 예상·확정·수령 수입, 미수령, 수령률 게이지 + **공정별 공수 요약**(타일 12 · 목공 1 · 전기·설비 1 …)
- 날짜 선택 → 공수 카드에 **공정 태그 배지**, 임금 수령 체크, 수정/삭제
- **공수 추가/수정 시트**: **공정 선택 칩**(6종, 선택 시 그 공정 기본 일당 자동 입력), 현장명, 공수(0.5 단위), 일당, 상태, 임금 수령, 메모

### ④ 내 프로필
- 기술자 프로필: 등급(기공), 경력, 활동 지역, **주력 공정(복수)**, 시공 스킬(공정별 그룹), **공정별 보유 공구**, 한 줄 소개 — 수정 시트에서 실제 편집
- **안심 이력 배지**: 노쇼 0회 · 임금체불 0건 · 최근 24개월 기준
- 지표: 완료 현장 / 평균 평점 / 재요청률 / 지원 중
- **시공 포트폴리오**: 공정 필터(전체/타일/목공/전기·설비…) + 카드에 공정 배지·규격·면적·발주처
- **발주처 후기**: 공정 배지와 함께 표시
- **본인인증 카드**: 휴대폰 인증 완료(마스킹 번호) · 발주처 사업자 인증 상태
- **계정 관리**: 로그인 수단, 역할·계정 전환, 알림함, **약관 및 정책 보기**(이용약관·개인정보 처리방침·위치기반 서비스)
- **광고 · 제휴**: **`광고 · 제휴 문의`** 메뉴 → 업체명·담당자·연락처·광고 희망 업종(폐기물·스카이 / 1톤 용달 / 온라인 건재몰 / 전동공구·부자재 / 세무·보험 / 차량 리스 / 기타) + 문의 내용 입력 → **접수번호(AD-YYYYMMDD-XXXX)** 발급(데모 접수)
- **안전센터**: 노쇼·임금체불 신고, 내 신고 내역(접수번호·상태), 긴급 상담
- 설정: 프로필 수정, 데모 데이터 초기화(두 번 눌러 실행), 로그아웃(두 번 눌러 실행)
- 발주처 계정은 업체명·사업자 인증·등록 공고 중심의 **발주처 프로필**로 전환됩니다.

### ⑤ 시작 · 로그인 · 회원가입
- 앱 첫 진입(로그인 정보 없음)과 로그아웃 후 **간소화된 시작 화면**: 로고 + 한 줄 슬로건(`공정별 현장 구인·구직`) + 공정 한 줄, **역할 선택 2개**(일자리 찾기 · 기술자 / 인력 구하기 · 발주처), **카카오 원터치 + 네이버·Apple·휴대폰 컴팩트 버튼**, `지금 공정잡에는` 요약, **로그인 없이 둘러보기**, 약관 안내 — **390×844 한 화면에 모두 표시**(스크롤 없이)
- **간편 로그인 4종**: 카카오 · 네이버 · Apple · 휴대폰 번호 — 선택한 역할에 맞춰 가입 진행
- **회원가입 4단계**: ① 이름·휴대폰 → ② **인증번호 발송/확인(데모 6자리, 화면에 표시)** → ③ 주력 공정·경력·활동 지역(기술자) 또는 업체명·사업자등록번호 인증(발주처) → ④ 필수 약관 3종 동의(이용약관·개인정보·위치기반)
- 상단 **로그인** 버튼: 최근 계정 카드 원터치 로그인 + 휴대폰 번호·인증번호 로그인
- **로그인 없이 둘러보기** 지원(지원·공고등록은 로그인 필요 안내)
- 가입·로그인 정보는 **AsyncStorage**에 저장되어 새로고침·재실행 후에도 유지되며, 로그아웃 후 최근 계정으로 다시 테스트할 수 있습니다.
- 역할에 따라 **기본 탭**(기술자=일자리, 발주처=공고등록)과 헤더·프로필 배지가 달라집니다.

### ⑥ 알림함 · 안전센터
- 헤더 종 아이콘 → **알림함 시트**: 지원 합격 확정, 연락처 공개, 내 주변 신규 공고, 공수 정산 리마인더, 안전센터 처리 결과
- 알림을 누르면 **읽음 처리** + 연결된 공고 상세로 이동, 하단에서 **모두 읽음 처리**
- **노쇼·임금체불·허위공고 신고 모달**: 신고 대상(발주처·현장 / 작업자) 선택, 사유 선택, 상세 내용(10자 이상), 신고자 인증 정보 확인 → **접수번호(R-YYYYMMDD-XXXX)** 발급 및 접수 완료 안내(24시간 내 확인·소명 절차)
- 공고 상세 하단과 내 프로필 → 안전센터에서 진입, 접수 내역은 프로필에 표시

## 5. 정적 웹 빌드 · GitHub Pages 배포

```bash
npm run build:web     # expo export --platform web + scripts/postbuild-web.mjs
# → dist/ 에 index.html, 404.html, .nojekyll, _expo/, assets/ 생성
```

- `app.json`의 `expo.experiments.baseUrl` = `/gongjeongjob` → GitHub Pages 저장소 이름(`https://<user>.github.io/gongjeongjob/`)에 맞춘 서브패스로 모든 번들이 로드됩니다.
  **저장소 이름을 바꾸면 이 값도 함께 바꿔야 합니다.**
- `dist/.nojekyll`이 있어 `_expo/` 폴더가 그대로 서빙되고, `404.html`이 index 복사본이라 하위 경로 직접 접근도 앱으로 진입합니다.
- 배포 방법 1(자동): 저장소 루트에 이 프로젝트를 올리고 **Settings → Pages → Source: GitHub Actions** 선택 → `main` 푸시 시 `.github/workflows/deploy-pages.yml`이 빌드·배포합니다. (워크플로는 저장소 루트가 `tile-job-app`인 경우 기준입니다.)
- 배포 방법 2(수동): `npm run build:web` 후 `dist/` 폴더 내용을 `gh-pages` 브랜치 루트에 올립니다.
  ```bash
  npx gh-pages -d dist        # gh-pages 패키지 사용 시
  ```
- QA 스크립트는 결과물을 실제로 `http://127.0.0.1:<port>/gongjeongjob/` 서브패스에서 열어 검증합니다.

### 검증 명령
